## Principios desta pasta

- Todo numero deve ter fonte e motivo.
- Todo score deve explicitar inputs e formula.
- Todo artefato deve ser rastreavel ate o backlog original.
- Todo item fora de escopo deve ser registrado, e nao apenas omitido.

## Escopo deste pacote

Inclui briefing, memoria de calculo, backlog priorizado, plano de sprints, forecast probabilistico, arquitetura alvo AWS ECS Fargate, checklist de stores e preparacao para reescrita do GitHub Project.

Nao inclui ainda a execucao remota do board, pois este ambiente nao possui `gh` CLI instalado. A estrategia para isso esta documentada em `07-github-board/`.
