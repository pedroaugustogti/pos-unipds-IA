## Aulas desta unidade

### Aula 22 — Langfuse: tour e instrumentação por nó

Arquivo: [`AULA_22_LANGFUSE.md`](./AULA_22_LANGFUSE.md)

O que você deve sair sabendo:

- Explicar por que uma aplicação em produção precisa de observabilidade e o que é telemetria.
- Preparar um projeto no Langfuse e instrumentar o grafo do agente para enviar a telemetria.
- Reconhecer o papel do OpenTelemetry como padrão aberto e do padrão interceptor na instrumentação.

### Aula 23 — Métricas, budget de tokens e rate limiting

Arquivo: [`AULA_23_METRICAS_BUDGET.md`](./AULA_23_METRICAS_BUDGET.md)

O que você deve sair sabendo:

- Diferenciar telemetria, que registra item a item, de métrica, que é o valor agregado ao longo do tempo.
- Criar contadores de tokens e de custo e expô-los em um endpoint de métricas.
- Implementar o rate limiting e um orçamento diário de tokens como mecanismos de controle de custo e de volumetria.

### Aula 24 — README e desligando o ambiente pelo Console

Arquivo: [`AULA_24_README_TEARDOWN.md`](./AULA_24_README_TEARDOWN.md)

O que você deve sair sabendo:

- Documentar o projeto em um README com visão geral e diagramas Mermaid gerados com apoio do agente.
- Explicar por que o Mermaid é adequado para registrar arquitetura quando se trabalha com IA.
- Encerrar o projeto no console do Google Cloud para não continuar pagando pelos recursos provisionados.
