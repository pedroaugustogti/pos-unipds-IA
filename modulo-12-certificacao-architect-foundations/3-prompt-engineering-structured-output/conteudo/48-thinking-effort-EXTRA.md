# 4.7 — Thinking / effort vs structured output

## Objetivo
Nao confundir raciocinio estendido com garantia de schema.

## Analogia
Pensar mais alto (thinking) ≠ preencher formulario valido (schema).

## Pontos de prova
- Thinking melhora julgamento; **nao** substitui validacao
- Controle de loop continua em `stop_reason`, hooks, schemas
- Nao parsear thinking como API estavel de terminacao
- Effort/budget ajusta profundidade; schema garante forma

Explique em 2 frases por que "ligar thinking" nao resolve JSON malformado.
