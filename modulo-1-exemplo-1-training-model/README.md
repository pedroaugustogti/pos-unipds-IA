# Atividade: treino e inferência com TensorFlow.js

Este diretório é o **Módulo 1 — Exemplo 1** (`modulo-1-exemplo-1-training-model`) e introduz **machine learning no Node.js** com `@tensorflow/tfjs-node`.

## Objetivo da atividade (Pós)

Compreender o fluxo básico de ML no servidor:

1. Carregar e preparar dados (tensores)
2. Definir um modelo simples
3. Treinar ou executar inferência em ambiente Node.js

## Como realizar a atividade

```bash
npm install
npm start
```

O script usa `node --watch` em `index.js` para recarregar ao editar.

### Critérios de sucesso

- [ ] Projeto roda sem erros
- [ ] Você identifica onde ocorre treino vs inferência no código
- [ ] Entende o papel dos tensores e da normalização

## O que observar

Fluxo típico: tensores, normalização e rede pequena alinhada ao conteúdo teórico da disciplina.

## Relação com o Módulo 1

Base para exemplos posteriores (e-commerce, embeddings): o ML deixa de ser só teoria e passa a rodar em JavaScript.
