## Objetivos

1. Change `add-cypress-e2e` via OpenSpec
2. Specs Cypress em `frontend-cypress-e2e/` (projeto Nx: `frontend-e2e`)
3. `npx nx e2e frontend-e2e` e `npx nx open-cypress frontend-e2e`

## Comandos

```bash
cd cfp-platform
npx nx run-many -t serve -p api frontend
npx nx open-cypress frontend-e2e
```
